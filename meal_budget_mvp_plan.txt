================================================================================
[MVP 기획 요약] 주간 식비 방어형 나만의 AI 영양사
================================================================================

1. 서비스 핵심 컨셉
--------------------------------------------------------------------------------
- 타깃: 1인 가구, 자취생, 사회초년생 (식비 절감 + 메뉴 고민 해결)
- 한 줄 정의: "주 3만 원으로 해결하는 평일 저녁 5끼 식비 방어 식단 플래너"
- 차별점:
  1) 식재료 돌려막기(재고 소진 동선)로 버리는 재료 0개 달성
  2) 복잡한 최저가 API 대신 현실적인 가성비 식재료 3~4가지 집중 활용
  3) 1끼 15분 내외 초간단 현실 레시피 제공

2. 사용자 플로우 (UX Flow)
--------------------------------------------------------------------------------
[Step 1] 목표 설정
- 이번 주 평일 저녁(월~금 5끼) 목표 예산 선택 (예: 3만 원 / 4만 원)

[Step 2] 기본 양념 프리셋 체크 (빠른 온보딩)
- "한국 자취방 기본 세트"가 기본 ON 상태로 제공 (없는 것만 해제)
  * 디폴트 품목: 식용유, 소금, 설탕, 진간장, 고춧가루, 다진 마늘, 참기름, 굴소스/MSG

[Step 3] AI 식단 및 장보기 리스트 자동 생성
- 이번 주 핵심 식재료 3~4가지 자동 픽 (예: 돼지 앞다리살, 두부, 애호박, 팽이버섯)
- 5일 치 저녁 식단표 + 조리 시간 15분 컷 레시피
- 장보기 리스트 분리 출력 (구매 품목 vs 보유 양념)

[Step 4] 액션 & 실행
- 장보기 리스트 원클릭 텍스트 복사 (마트 방문 또는 배송 장바구니용)
- 요리 시 잔여 식재료 연결 안내 (예: "월요일 남은 애호박 반 개는 수요일 찌개에 투입")

3. MVP 식단표 및 장보기 예시 (예산: 3만 원 컷)
--------------------------------------------------------------------------------
[구매할 식재료 (예산 약 28,000원 소진)]
1) 돼지 앞다리살 600g (약 7,500원)
2) 두부 2모 (약 2,500원)
3) 애호박 1개 (약 1,500원)
4) 팽이버섯 3팩 (약 1,500원)
5) 양파 1망 (약 3,000원)
6) 대파 1단 (약 2,500원)
7) 깐마늘/계란 10구 등 보조재 (약 5,000원)

[주간 5일 저녁 식단표]
- 월: 돼지고기 애호박 볶음 (애호박 1/2개, 돼지고기 150g 사용)
- 화: 두부 조림 & 팽이버섯 볶음 (두부 1모, 팽이버섯 1팩 사용)
- 수: 돼지고기 듬뿍 김치찌개 (돼지고기 200g, 두부 1/2모 사용)
- 목: 애호박 된장찌개 & 두부 부침 (애호박 1/2개, 두부 1/2모 사용)
- 금: 냉털 돼지고기 야채 볶음밥 (남은 돼지고기, 자투리 채소, 팽이버섯 전량 소진)

4. MVP 개발 범위 (Scope)
--------------------------------------------------------------------------------
[포함 (Must Have)]
- 목표 예산 입력 UI
- 기본 양념 태그 선택기 (Default True)
- LLM 기반 5일 식단 및 간이 레시피 생성 엔진
- 장보기 리스트 클립보드 복사 기능

[제외/보류 (Later)]
- 실시간 대형마트 최저가 크롤링 API 연동 (추정 시세 프롬프트 룰로 대체)
- 이커머스 자동 장바구니 담기 (복사 버튼으로 대체)
- 정밀 칼로리/영양 성분 분석표 (단백질 재료 1종 필수 포함 룰로 단순화)
